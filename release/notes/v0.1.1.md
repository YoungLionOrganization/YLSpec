# YLSpec 0.1.1

This patch keeps document format 0.1 and frame 0.1 unchanged while adding
C-backed language adapters and correcting post-mutation validation.

## Changes

| Area | Result |
|---|---|
| Node.js | Stable Node-API C addon, ESM/CommonJS initialization, packaged platform binaries |
| Browsers and React | The same C core compiled to WebAssembly, async initialization, real-browser verification |
| TypeScript | Typed document, temporal, limits, profile, error, and reader contracts |
| Java and Kotlin | JNI-backed Java API and Kotlin extensions, exact Long and temporal values |
| Android | API 26+ JNI-only AAR for armeabi-v7a, arm64-v8a, x86, and x86_64 |
| Core correctness | Revalidate configured depth after mutation; tolerate null capability entries |
| Distribution | npm tarball, Maven-layout bundle, JARs, AAR, checksums, and registry publishing workflows |
| VS Code | `.ylspec` highlighting, snippets, metadata completions, hover help, C-backed worker diagnostics, and opt-in semantic formatting |

JavaScript integers use bigint. Java integers use Long. Neither adapter silently
converts exact temporal literals to lower-precision platform date/time values.
All parsers remain the C reference implementation. Browser WebAssembly is a
different build target, not a separate JavaScript parser.

## Verification and compatibility

GitHub verification includes the existing Python/C suite, native Node and JNI
execution, TypeScript consumers, React in Chromium, Android cross-compilation,
and an API 26 emulator smoke test. Published workflow results are the source of
truth for completed checks. Runtime code does not download binaries during npm
installation. Core source distributions retain dependency notices.

Registry uploads for npm and Maven Central have separate manual workflows and
require the corresponding account setup. The GitHub/PyPI release pipeline
includes their built distributions as downloadable assets regardless of registry
availability. Existing Python signatures and YLSpec framing stay compatible.

The universal `ylspec-0.1.1.vsix` adds standalone document editing in VS Code
1.95+ desktop/remote extension hosts. Install through **Install from VSIX…**.
Unknown custom profiles are warnings; invalid syntax and unsupported mandatory
features are errors. Formatting is disabled by default because it removes
comments. Browser-only vscode.dev and binary host-container editing remain
outside the editor's scope. Marketplace publication requires its own publisher
credential and separate workflow.

Install Python with `python -m pip install ylspec==0.1.1` after PyPI publication.
Native C archives contain static/shared libraries, headers, CLI binaries, CMake
exports, and notices. The npm tarball contains all verified Node targets and
browser WebAssembly. The JVM ZIP preserves Maven repository layout; individual
Java/Kotlin/native JARs and the Android AAR are also attached. `SHA256SUMS` and
`build-manifest.json` record the asset hashes and source commit.
